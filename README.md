# Wine Dataset Audit

Arthur Cox III — COMP365 data-quality audit of the scikit-learn Wine dataset. Profiles missing values, duplicates, class balance and feature distributions; produces an audited dataset. No classifier is trained in this project.

Open `Cox_Arthur_Build6.ipynb` in Jupyter or Colab and run in order. Requires pandas, NumPy, matplotlib and scikit-learn. Original notebook retains its dataset attribution and AI-assistance disclosure.
